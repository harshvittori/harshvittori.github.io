Spaceship

01Buy the domain

We compared five registrars (BigRock, Hostinger, GoDaddy, Cloudflare, Spaceship) with real carts. Spaceship was cheapest for the first year and gives privacy free, so haritt.com was bought there.

Log in with harittgroup@gmail.com
1

Search and add haritt.com to cart

Open www.spaceship.com, search haritt.com, add it, and set registration to 1 year.

Apply promo code COM67. The first year came to $3.80 (≈ ₹370 at ₹96.4 per $).

Watch out"VPN or Proxy detected" blocks the code. Turn off any VPN or proxy and reload the cart.
2

Fill domain contacts and pay

Fill your name and address. Leave Organization empty: Haritt is not registered yet. Privacy is free and stays on, so your phone and email stay hidden from spam callers.

3

Check it in Domain Manager

Go to Domain Manager. You should see haritt.com, expiry Oct 7, 2027, privacy Private.

Watch outTurn Auto-renew ON and verify the Spaceship email before Oct 22, or the domain can be suspended.
Cloudflare

02Point the domain to Cloudflare

Cloudflare runs our DNS (the address book that says where haritt.com lives) and our email forwarding. The free plan is enough.

Log in with harittgroup@gmail.com
1

Create the account and add the domain

Sign up at dash.cloudflare.com/sign-up, choose Add a domain, type haritt.com and pick the Free plan.

2

Clean up the scanned records

Cloudflare copies the records it finds. The two A records (54.149… and 34.216…) were Spaceship's parking page, so we deleted them.

3

Add the GitHub Pages records

Add four A records for @ and one CNAME for www. Keep the cloud grey (DNS only), because GitHub makes its own HTTPS certificate.

A @185.199.108.153185.199.109.153185.199.110.153185.199.111.153CNAME wwwharittgroup.github.io
Watch outOrange cloud (Proxied) on these records breaks GitHub's HTTPS check. Keep them grey.
4

Change nameservers in Spaceship

Cloudflare gives two nameservers. In Spaceship open haritt.com → Nameservers → Custom, and paste:

conrad.ns.cloudflare.comsneh.ns.cloudflare.com
5

Domain active

When the status says "Your domain is now protected by Cloudflare", DNS is live.

GitHub Pages

03Host the website

GitHub Pages hosts the haritt.com website from a repository, at no cost. Every push to the main branch goes live in 1–2 minutes.

Log in with harittgroup GitHub org (owner: harshvittori)
1

Create the organization

Go to github.com/organizations/new, pick the Free plan. haritt was taken, so the org is harittgroup.

2

Create the repo and turn on Pages

Create the public repo harittgroup/haritt.com. Then Settings → Pages: Source Deploy from a branch, branch main, folder / (root), Save.

3

Add the custom domain and HTTPS

In the same Pages screen type haritt.com under Custom domain and Save. Wait for DNS check successful, then tick Enforce HTTPS.

TipThe repo also contains a file named CNAME with haritt.com inside. Don't delete it, or the domain comes off.
4

How updates go live

The site is plain HTML generated by build.py. Change the content, run the build, commit and push to main. GitHub publishes it in 1–2 minutes.

TipIf the site opens on mobile data but not on your WiFi, it is your WiFi's old DNS memory. Turn on Chrome Secure DNS (Cloudflare) and run ipconfig /flushdns.
Subdomain

04Move HV World to hvworld.haritt.com

HV World used to live at harshvittori.github.io. We gave it our own address. Old links still work: GitHub redirects them.

Log in with harshvittori5678@gmail.com (Firebase / Google Cloud)
1

DNS record in Cloudflare

Add a CNAME: name hvworld → harshvittori.github.io, grey cloud. We first tried a redirect rule; it is deleted now.

2

Tell GitHub the new address

In the HV World repo, Settings → Pages → Custom domain: hvworld.haritt.com, then Enforce HTTPS. The repo has a CNAME file with the same name.

3

Allow the new address in Firebase and reCAPTCHA

Sign-in breaks on a new domain until it is allowed:

  • Firebase → Authentication → Settings → Authorized domains: add hvworld.haritt.com.
  • Google Cloud → reCAPTCHA: open the site key and add hvworld.haritt.com to its domains.
Watch outUsers have to sign in once again on the new address. Things saved only in the browser on the old address don't carry over.
Email

05Company email: harsh@, admin@, hello@

Zoho's free plan was not offered to us, so we used Cloudflare Email Routing (free) to receive, and Gmail "Send mail as" to reply from the same address.

Log in with harittgroup@gmail.com
1

Turn on Email Routing

Cloudflare → haritt.com → Email → Email Routing.

2

Add the missing DNS records

Open Settings and click Add missing records. Cloudflare adds 3 MX, 1 DKIM and 1 SPF record by itself.

3

Create the addresses

Routing rules → Create routing rule. Write the name (e.g. harsh), action Send to an email, destination harittgroup@gmail.com. The first time, Gmail gets a verify mail: click it.

TipNeed a new one, like pulkit@? Same steps. The destination can be that person's own Gmail.
4

Reply from @haritt.com (Gmail "Send mail as")

First turn on 2-Step Verification and create an App password in harittgroup@gmail.com.

Then Gmail → Settings → Accounts and Import → Add another email address. Enter the name and address, then:

SMTP serversmtp.gmail.comPort587 (TLS)Usernameharittgroup@gmail.comPasswordthe 16-letter app password

Gmail sends a code to the new address (it lands in the same inbox). Confirm it. Done for all three.

Watch outCloudflare's mail servers (route1/2/3.mx.cloudflare.net) only receive. They can't be used as SMTP. Also, accounts with Advanced Protection (passkey-only) can't make app passwords, so send-as lives in harittgroup@gmail.com.
Claude

06Claude Console and the Startups application

We created an organization in the Claude Console with harsh@haritt.com and applied to Claude Startups. No money is needed for this.

Log in with harsh@haritt.com
1

Create the Console account

Go to platform.claude.com and sign up with harsh@haritt.com. Choose Organization.

2

Organization details

Name Haritt Group, keep "Allow @haritt.com emails to join" ticked, entity Small or medium business, country India.

3

How you will use the API

Outside India: No (can be changed later). Customers: External. Use cases: Multi-language Support, Information Extraction, Transcript Analysis, Education, Coding.

4

Review questions

Legal/medical/financial advice: No. Users under 18: Yes (HV World is open to all ages, so we follow Anthropic's rules for minors when Claude goes into HV AI).

5

Skip credits, skip invites

On "Buy usage credits" click Skip for now. On "Invite members" click Continue without inviting.

6

Apply to Claude Startups

Form: platform.claude.com/offers/startups-application. Company Haritt Group, Founder, website haritt.com, India, Bootstrapped, 0–20% AI spend on Anthropic, plus what we build and need.

7

Result and what next

First result: not approved, because the company could not be verified (not registered, new domain, no company page).

Before reapplying, make Haritt verifiable, all free:

  • Udyam registration with Aadhaar and PAN (free, government certificate)
  • LinkedIn company page "Haritt Group" with haritt.com
  • Crunchbase profile

Then reapply and add the Udyam number and LinkedIn link.
