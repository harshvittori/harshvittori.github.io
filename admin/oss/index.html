The program

What is Claude for Open Source?

A quick explainer for anyone new to it.

In one line

A thank-you program from Anthropic, the company behind Claude: people who keep open-source software running get 6 months of Claude Max 20x free, the biggest personal Claude plan.

It's personal, not for a company: you apply with your GitHub account and a repository, and show your work and its reach.

At the end of the 6 months the free plan ends. Anthropic emails before it does.

Who should apply (any one is enough)

  • Maintainer: 500+ dependent repos, 100+ dependent packages, or 200,000+ monthly downloads
  • Core contributor on a big project (Python, Rust, Node.js, Kubernetes, Linux and similar)
  • Active contributor: 100+ merged pull requests in repos you don't own, last 12 months
  • Community builder: 20+ outside contributors with merged pull requests in one of your repos, last 12 months
  • Critical infrastructure: a repo with OpenSSF criticality 0.4+

Don't quite fit? If something the ecosystem quietly depends on, apply anyway.

Bonus: OpenAI runs a similar program, Codex for Open Source (6 months of ChatGPT Pro with Codex). This same plan gets us ready for both.

Ground rules

How we play it

Real contributions only

No spam pull requests, no fake accounts, no padding numbers. Maintainers notice, and it can get us banned from projects.

No secrets in public code

Scan before every push. API keys, passwords and private data never go into a public repo.

Steady beats bursts

The counts are for the last 12 months, so a little every week matters more than one big push.

No guarantee

Meeting a route makes us eligible to apply. Anthropic decides. Startups comes first; this one is the next goal.
