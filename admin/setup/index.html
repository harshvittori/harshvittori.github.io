Free · 10 min

Add the DNS records for the website5 steps
Free · 5 min
  1. Cloudflare → haritt.com → DNS → Records → Add record, 4 times:
  2. Type A · Name @ · IPv4 185.199.108.153 · Proxy status: DNS only (grey cloud)
