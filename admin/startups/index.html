Rules we follow

Never exaggerate. No made-up users, revenue, funding or partners. A false number is the surest way to get rejected, and can block us later.
No guarantee. Meeting the rules makes us eligible to apply. Anthropic reviews every application and decides. Most decisions come within minutes, the rest in 2–3 business days.
No deadline, but don't wait. Applications are open on a rolling basis. The terms say Anthropic can cancel or change the program at any time, so we apply as soon as phases 1–4 are done.
Keep secrets safe. The Claude API key never goes into website code or GitHub. It lives in a small server (step 2.3).
